Downloads

    A wrapper link, such as fileguard.cc's or filecrypt.cc's, or a web page that links a release's files (a blog's or forum's post), holds a release's files, on one host or on many. Haul unwraps it as soon as you add it, and each file joins the list once: the same file from another host, on this wrapper or another one, becomes a mirror of it rather than a second download. The files wait for you to start them, here or in the list.

    Choose which hosts Haul uses and in what order. A file on several hosts downloads from the first of your preferred hosts that has it (star a host to add it; drag it by its grip, or use its arrows, to reorder), otherwise from the fastest of the others. A host switched off is never used. The gauge limits how many files download from a host at once, and the folder keeps its files in a subfolder.

    What downloads go out through. Hosts limit what one address may fetch (downloads at once, daily allowances, waits), so every address Haul can use is another share: a new one from your router, proxies, or a VPN service's servers.
