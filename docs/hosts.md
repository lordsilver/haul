# Hosts

How Haul turns each host's link into a file, what it needs from you, and what has been checked against the real host. What happens after that (mirrors, retries, cooldowns) is the same for every host and is in [How downloads behave](downloading.md).

Each host Haul knows is one entry of a table in `crates/haul-core/src/hosts/mod.rs` (`KNOWN`): the names it goes by, the code that serves it, the account settings that unlock more, what a free user gets where it was measured (pixeldrain: 5 downloads at once and 6 GB a day at full speed per address, then 1 MiB/s), and whether it says how much an address has left today. The engine and the **Sites** view read that table rather than host names. Resolvers live in `crates/haul-core/src/hosts/`; every one is covered by tests against a local stand-in for the host's API (`resolver_tests.rs`), which pins the requests Haul sends and how it reads the answers. Whether a host still answers that way is a separate, live question, tracked in the last column.
